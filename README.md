A complete story in exactly six words, written by a small program for make.fun's "Six Words, One Story" bounty.

> Her last voicemail still says tomorrow.

Six words: a voice from someone gone, still promising a tomorrow that will never come. Beginning, middle, and turn in one line — and the reader fills in the rest.

## Run it

```sh
node main.ts
```

It writes the story to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), exactly six words, 39 characters, deterministic on every run.
